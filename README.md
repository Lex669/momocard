# momocard

**墨墨记忆卡（Markji）制卡助手**

把知识点、笔记、文档转换为可直接粘贴进[墨墨记忆卡（Markji）](https://open.maimemo.com/#/#%E5%A2%A8%E5%A2%A8%E8%AE%B0%E5%BF%86%E5%8D%A1%E5%88%B6%E5%8D%A1%E6%8C%87%E5%8D%97)的卡片文本——语法正确、重点难点精准挖空、配色统一美观。

## 特性

| 特性 | 说明 |
| --- | --- |
| **语法正确** | 内置官方制卡指南完整语法（挖空、样式、选择题、公式、问答分隔等），输出前逐卡执行 12 项自查清单 |
| **易于背诵** | 一个知识点一张卡；挖空只挖重点、难点、易错点——核心概念、精确数值、因果关键环节、易混淆差异，而非随意挖空 |
| **忠实原文** | 不改写、不压缩材料措辞，只做分点重排与挖空；助记（口诀、陷阱）放在 `---` 之后 |
| **美观统一** | 统一配色规范（红=易错、蓝=定义、绿=补充、黄底=关键词），结构化的卡片版式 |
| **易混淆辨析** | 易混淆概念优先做成选择题，选项正误标记、多选自动 `multi` |
| **章节化输出** | 输入一整份资料即可按章节（`###章节名`）组织、用 `===` 分隔卡片，整份卡集一次复制粘贴导入 |

## 快速开始

### 安装

本插件为纯 Markdown，无需构建，采用手动 zip 安装：

1. 下载本仓库 zip（GitHub 页面 *Code → Download ZIP*），或克隆后在本仓库根目录压缩（保持 `.claude-plugin/plugin.json` 与 `.codex-plugin/plugin.json` 相对路径不变）：

   ```powershell
   tar -a -c -f momocard.zip .claude-plugin .codex-plugin commands skills README.md
   ```

2. 在 Qoder / Claude / Codex 的插件管理中选择本地 zip 安装。
3. 重启后即可使用 `/momocard` 命令，或在对话中直接提出制卡需求。

### 使用方式

**斜杠命令**——参数可以是知识点、笔记文本或文件路径：

```
/momocard 牛顿第二定律、动量守恒
/momocard @notes/chapter3.md
```

**对话触发（技能）**——提到制卡相关话题即可自动触发：

```
帮我把这些知识点做成墨墨记忆卡：光合作用、细胞呼吸、呼吸作用场所辨析
把这份笔记转成记忆卡（粘贴笔记或给出文件路径）
```

材料包含多个知识点时，会先给出拆分方案（哪些章节、每个知识点各一张卡），确认后按章节分批生成（每批 ≤ 20 张）。

## 输出效果

按章节组织：`###章节名`（如 `###ch1`）独占一行开启章节，章节内卡片用 `===` 独占一行分隔；整体放在一个代码块中，复制后粘贴到墨墨记忆卡即可。

```
###ch1
[P#H1,center#光合作用]
[T#B,!1e88e5#光合作用]是绿色植物通过[T#B#叶绿体]，利用光能，把[F#1#二氧化碳和水]转化为[F#2#储存能量的有机物]，并释放[F#3#氧气]的过程。
===
[P#H1,center#有氧呼吸三阶段场所]
[P#L#糖酵解：场所是[F#1#细胞质基质]]
[P#L#柠檬酸循环：场所是[F#2#线粒体基质]]
[P#L#氧化磷酸化：场所是[F#3#线粒体内膜]]
---
[T#!43a047#口诀：质里起步，质中转圈，膜上产能。]
===
[P#H1,center#场所辨析]
真核细胞中进行有氧呼吸的主要场所是？
[Choice##
- 叶绿体
* 线粒体
- 核糖体
]
###ch2
[P#H1,center#光反应与暗反应]
光反应发生在[F#1#类囊体薄膜]，暗反应发生在[F#2#叶绿体基质]。
```

以上输出包含 2 个章节、4 张卡片，覆盖挖空卡、列表挖空卡、选择题三种卡型；`---` 之后为助记，绿色口诀便于快速回忆。

## 工作流程

1. **读参考文件**——加载官方语法参考与卡片设计规范，以完整示例校准输出水准
2. **分析材料**——判断知识点数量与形态（事实/问答/辨析/列举/公式/流程），跳过水分内容
3. **设计卡片**——选卡型、按挖空策略定挖空点、易混淆概念做选择题
4. **编写排版**——按统一配色与结构规范输出，原文措辞一字不改
5. **逐卡自查**——语法 12 项检查清单 + 设计 5 项自查
6. **章节化输出**——按逻辑结构分章，章节内由浅入深（概念→细节→辨析→测验）
