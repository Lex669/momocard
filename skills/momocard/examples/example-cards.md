# 墨墨记忆卡完整示例

> 每个示例给出可直接粘贴的批量输出（`###` 划分章节、`===` 分隔卡片）与设计说明。输出水准以此为校准基准。

## 示例一：生物 — 两个章节，混排挖空/列表/问答/选择题

```
###ch1
[P#H1,center#光合作用]
[T#B,!1e88e5#光合作用]是绿色植物通过[T#B#叶绿体]，利用光能，把[F#1#二氧化碳和水]转化为[F#2#储存能量的有机物]，并释放[F#3#氧气]的过程。
===
[P#H1,center#有氧呼吸三阶段场所]
[P#L#糖酵解：场所是[F#1#细胞质基质]]
[P#L#柠檬酸循环：场所是[F#2#线粒体基质]]
[P#L#氧化磷酸化：场所是[F#3#线粒体内膜]]
---
[T#!43a047#口诀：质里起步，质中转圈，膜上产能。]
===
[P#H1,center#光反应与暗反应]
光反应发生在[F#1#类囊体薄膜]，暗反应发生在[F#2#叶绿体基质]。
---
[T#U,!e53935#易错]：光反应不产生葡萄糖，只产生[F#3#ATP和NADPH]。
###ch2
[P#H1,center#呼吸场所辨析]
真核细胞中，下列过程发生在细胞质基质中的有？
[Choice#multi#
* 糖酵解（有氧呼吸第一阶段）
- 有氧呼吸第三阶段
- 柠檬酸循环
* 无氧呼吸全过程
]
===
[P#H1,center#光合色素吸收峰]
叶绿素主要吸收的光是？
[Choice##
- 黄光和绿光
* 红光和蓝紫光
- 绿光和红外光
]
```

设计说明：

- 章节划分跟随知识模块：ch1 是"光合与呼吸的基本过程"，ch2 是"场所与吸收的辨析测验"；章节名称（ch1、ch2）可按需改为章节主题。
- 第一张卡挖"原料、产物、氧气"三处核心要素，编号独立（1/2/3）逐个自测；定义主干保持完整，提供回忆线索。
- 第二张卡是列表卡：三个场所各挖一处；口诀用绿字放在 `---` 之后，先测后助记。
- 第三张卡用红字标出高频易错点"光反应不产生葡萄糖"，并再挖一处易错产物；挖空合计 3 处，符合上限。
- ch2 的辨析题干扰项全部来自真实的易混概念；多选写 `multi`，单选只留一个 `*` 且不写参数；都不写 `fixed`，随机排列防止背选项位置。
- 章节内卡片按 概念→细节→辨析 由浅入深排列；新章节直接以 `###ch2` 开始，其前不加 `===`。

## 示例二：历史 — 单章节，精确信息与编号分组

```
###ch1
[P#H1,center#辛亥革命]
辛亥革命爆发于[F#1#1911]年，首义地点是[F#2#武昌]，推翻了[T#B#清王朝]的统治。
===
[P#H1,center#三民主义]
孙中山在《民报》发刊词中，将同盟会纲领阐发为三民主义：
[P#L#[F#1#民族主义]：驱除鞑虏，恢复中华]
[P#L#[F#1#民权主义]：创立民国]
[P#L#[F#1#民生主义]：平均地权]
---
[T#B,!1e88e5#核心是民权主义]。
===
[P#H1,center#辛亥革命的意义与局限]
辛亥革命结束了两千多年的[F#1#君主专制制度]。
---
[T#U,!e53935#注意]：它[T#U,!e53935#没有]改变中国[T#B,!e53935#半殖民地半封建社会]的性质。
```

设计说明：

- 第一张卡挖年份、地点等精确信息；"推翻了清王朝"不挖，主干可见才能定位回忆方向。
- 第二张卡三个主义用**相同编号**（同为 1 号组）：三者必须作为一个整体框架同时回忆，一起显示隐藏；释义行保留，回忆方向为"内容→名称"。
- 第三张卡把命题真假的限定词"没有"用红字加下划线强调——本考点最经典的易错处。

## 示例三：数学 — 公式卡与函数特征

```
###ch1
[P#H1,center#等差数列前 n 项和]
等差数列的前 n 项和公式是什么？
---
[E##S_n=\frac{n(a_1+a_n)}{2}=na_1+\frac{n(n-1)}{2}d]
===
[P#H1,center#求和公式的函数特征]
当公差 [F#1#d≠0] 时，前 n 项和 [F#2#S_n] 是关于 n 的二次函数，其图像是[F#3#抛物线]上的点。
---
[T#U,!e53935#注意]：d=0 时退化为一次函数，图像是直线上的点。
```

设计说明：

- 公式卡先问后答：`---` 分隔问题与答案，独立公式 `[E##...]` 从行首开始，LaTeX 反斜杠原样书写。
- 第二张卡考公式函数特征的判断性内容（d≠0、二次、抛物线），都是考试易错点；红色下划线标注条件变化。
- 需要在普通文字中显示中括号时必须转义，例如闭区间写作 `\[a,b\]`，否则会破坏语法解析。

## 示例四：单知识点整卡 — 一个知识点只生成一张卡

> 材料只讲一个知识点（一个概念/主题）时，不拆分、不建多张卡；不改写原文措辞，只做分点重排与挖空，助记放在 `---` 之后。

```
###结构异染色质
[P#H1,center#结构异染色质（组成型异染色质）]
[T#B,!1e88e5#结构异染色质]是细胞核内一类[F#1#永久性高度凝缩]的染色质，存在于[F#2#所有细胞类型及整个细胞周期]中，无[F#3#转录]活性。
[P#L#分布：主要分布于染色体[F#4#着丝粒区、端粒、次缢痕]等区域]
[P#L#组成：由简单的高度重复DNA序列（如[F#5#卫星DNA]）构成，[F#6#不编码蛋白质]]
[P#L#复制：[F#7#晚于常染色质]且[F#8#提前]凝缩]
[P#L#功能：在维持染色体[F#9#结构稳定性]、限制[F#10#转座元件]活动及形成[F#11#染色质区间性]中发挥关键作用]
[P#L#间期表现：在间期核中聚集形成[F#12#染色中心]，具有显著的[F#13#遗传惰性]，是异染色质的主要类型之一]
---
[T#!43a047#口诀]：无转录、不编码；复制晚、凝缩早；着丝粒、端粒、次缢痕。
[T#U,!e53935#陷阱]：与兼性异染色质对比记忆——"永久存在、所有细胞类型、整个细胞周期"是结构（组成型）异染色质的定界特征。
```

设计说明：

- 一个知识点 = 一张卡：本段材料只讲"结构异染色质"一个概念，不拆分，全部要点收在一张卡中；编号 1～13 连续且唯一，可逐点自测。
- 原文措辞一字未改：只按 分布/组成/复制/功能/间期表现 分点重排；"存在于……中""在……中发挥关键作用"等表达完整保留，分点标签仅吸收句首指代（"其""该区域"），不做同义压缩。
- 挖空全部落在考点上：定义边界（永久性高度凝缩、所有细胞类型及整个细胞周期）、否定限定词（无转录、不编码）、最易记反的"复制晚、凝缩早"、三个功能的关键词与"染色中心/遗传惰性"专名。
- `---` 之后是助记面（口诀、陷阱，可自由创作，不属于原文），先自测、后看提示。

## 示例五：默认输出形态 — 单知识点整卡、定义句限定词挖空、不加选择题

> 用户未明确要求辨析/测验题时，单知识点材料只出一张整卡挖空卡；定义句（"X是……的……"）中的定位、性质限定词必须挖空。

```
###膜转运蛋白
[P#H1,center#膜转运蛋白]
[T#B,!1e88e5#膜转运蛋白]是[F#1#镶嵌于]细胞质膜上的[F#2#功能性]蛋白质，负责介导[F#3#离子、小分子]等物质的跨膜运输，维持细胞内外[F#4#离子梯度及物质交换]。
[P#L#分类：根据[F#5#转运机制]可分为两类]
[P#L,I2#[F#6#载体蛋白]（如葡萄糖转运蛋白GLUT）：通过[F#7#特异性结合溶质并发生构象变化]实现转运，既可介导顺浓度梯度的[F#8#协助扩散]（如葡萄糖摄入），也可利用能量（如ATP水解或离子梯度）逆梯度[F#9#主动运输]（如钠钾泵）]
[P#L,I2#[F#10#通道蛋白]（如水孔蛋白AQP、离子通道）：形成[F#11#亲水性]跨膜通道，[F#12#仅]介导协助扩散]
[P#L,I2#离子通道具有[F#13#门控性]（电压、配体或应力激活），实现[F#14#高速]离子转运（如神经细胞动作电位）；水孔蛋白则特异性转运[F#15#水分子]]
[P#L#作用：对细胞[F#16#渗透平衡、营养吸收、信号转导及能量转换]至关重要，其功能异常可导致多种疾病（如[F#17#囊性纤维化]）]
---
[T#!43a047#口诀]：载体"结合变构"顺助逆主，通道"亲水开道"仅协助；离子通道门控高速，水孔专运水分子。
[T#U,!e53935#陷阱]：通道蛋白[T#U,!e53935#仅]介导协助扩散——主动运输（如钠钾泵）只属于载体蛋白。
```

设计说明：

- 默认输出形态：材料只讲"膜转运蛋白"一个概念，全部要点收进一张整卡挖空卡；用户未要求测验，因此不附加任何辨析选择题。
- 定义句限定词挖空：1 号"镶嵌于"（定位方式）、2 号"功能性"（性质限定）各自独立编号挖空——定义句限定词是必挖考点，不因字短、不起眼而漏挖。
- 编号 1～17 连续且唯一，可逐点自测；原文措辞一字未改，仅按 定义/分类/作用 分点重排；易混点"仅介导协助扩散"以限定词挖空 + 红字陷阱提示覆盖（替代选择题）。
- `---` 之后是助记面（口诀、陷阱，可自由创作，不属于原文），先自测、后看提示。
