# 墨墨记忆卡设计与挖空策略

> 卡片是背诵的工具，不是笔记的压缩。一个知识点对应一张卡片，挖空就是考题。
> 本文件回答三个问题：挖什么、用什么卡型、怎么排得好看。

## 原文原则（最高优先级）

**背诵材料是固定原文：不改写内容，只做两件事——分点重排 + 挖空。**

- 卡片措辞必须与原文一致：不压缩、不同义替换、不增删信息（如"存在于……中""在……中发挥关键作用"须完整保留）。
- 允许的加工仅有三类：
  1. 按类别分点重排并加类别标签（如 分布、组成、功能、复制、间期表现）；标签可吸收句首指代性主语（如"其""该区域"）。
  2. 在原文文字上挖空 `[F#n#...]`。
  3. 在 `---` 之后附加助记（口诀、陷阱提示）——助记不属于原文，可自由创作。
- 观感来自结构分点与样式克制，而不是改写文字。

## 一、挖空策略（核心）

墨墨记忆卡用于背诵知识点。挖空的内容 = 考试时需要主动回忆的内容 = 该知识点的**重点、难点、易错点**，而不是随意的文字。

### 1.1 该挖什么

按优先级判断，命中即挖：

1. **核心概念与术语**：定义中的被定义项、关键属性、专有名词。
   - 例："光合作用主要发生在[F#1#叶绿体]中"——叶绿体是核心概念。
2. **精确信息**：数值、单位、年份、人名、地名、比例、顺序。
   - 例："辛亥革命爆发于[F#1#1911]年"——年份是精确信息。
3. **因果关系中的关键环节**：原因、结果、前提条件、结论。
   - 例："温度升高导致[F#1#酶活性下降]，因此反应速率减慢"。
4. **易混淆的差异点**：与相似概念的区别之处、反向强调处。
   - 例："有氧呼吸[F#1#主要]在线粒体，糖酵解在[F#2#细胞质基质]"。
5. **判断性与限定性词语**："只、都、必须、不一定、可逆、主要、直接"等决定命题真假的词。
   - 例："溶质分子跨膜运输[F#1#不一定]需要载体蛋白"。
6. **公式的关键部分**：系数、指数、正负号、不等号方向。
   - 例："单摆周期 [E##T=2\pi\sqrt{L/g}] 中，与[F#1#摆球质量无关]"。

### 1.2 不该挖什么

- 虚词、连接词等语法成分（"的、了、因此、并且"）。
- 背景铺垫、题干引入、常识性内容。
- 无区分度的修饰语（挖了等于没挖）。
- 同一句子的主干全部挖空——上下文全丢，无法回忆。

### 1.3 粒度、挖空密度与编号分组

- **粒度：一个知识点 = 一张卡片**。材料只讲一个概念/主题时只生成一张卡，不拆分；含多个独立知识点时才逐个成卡。
- **挖空数量由知识点决定**：以覆盖该知识点的全部重点、难点、易错点为度，不设硬性上限；但每一处都必须是考点，绝不挖水分文字。
- **编号语义**（编号在整张卡内从 1 开始连续且唯一）：
  - 独立考点 → 不同编号，逐个自测。
  - 成对/互补/需要同时记住的内容 → 相同编号，一起显示隐藏。
    - 例："[F#1#收缩压]升高、[F#1#舒张压]降低"——脉压差增大，两半必须同时回忆。

### 1.4 提示充分性

挖空前后的文字必须能提供足够的回忆线索，让用户"想得起"而不是"猜不到"。上下文线索不足时，改用问答卡。

## 二、卡型选择

根据知识点形态选卡型；多个知识点组成的材料应混用多种卡型：

| 知识点形态 | 卡型 | 结构要点 |
|---|---|---|
| 事实陈述（主体+关键属性） | 挖空卡 | 陈述句 + `[F#n#...]` 挖核心 |
| 问题—答案（是什么/为什么/怎么做） | 问答卡 | 问题 → `---` → 简短答案 |
| 易混淆概念辨析 | 选择题 | `[Choice#...]`，干扰项用真实易混概念 |
| 要点列举（≥3 条） | 列表卡 | `[P#L#]` 逐条，每条挖一个关键词 |
| 公式、定理、推导 | 公式卡 | 陈述 + `---` + `[E##...]`，变量用挖空考 |
| 步骤、流程 | 流程卡 | 列表 + 挖空关键步骤/顺序 |

卡型设计细则：

- **问答卡**：问题要具体指向单一答案；答案尽量一行以内；追问细节时在答案后用 `[T#B#]` 或红字标易错处。
- **选择题**：干扰项必须是学习者真的会混淆的概念（近义、形近、相邻知识），不要凑数的荒谬选项；正确选项数量为 1 时只留一个 `*`，多个正确必须写 `multi`；一般不写 `fixed`（随机排列防背位置）。
- **列表卡**：每条一行；条目间平行；关键差异词挖空。
- **公式卡**：先用文字陈述物理意义，再给公式；LaTeX 反斜杠原样书写。

## 三、美化规范（统一观感）

### 3.1 统一配色体系

整个卡集使用同一套颜色语义，形成视觉记忆锚点：

| 语义 | 用法 | 示例 |
|---|---|---|
| 易错点、警告、否定性结论 | 红字 `!e53935`（重要时加下划线 `U`） | `[T#U,!e53935#没有]` |
| 高危易错强调（少量使用） | 红底 `!!ffcdd2` | `[T#!!ffcdd2#最易错]` |
| 核心定义、概念名 | 蓝字 `!1e88e5`（常与 `B` 组合） | `[T#B,!1e88e5#光合作用]` |
| 补充说明、例子、口诀 | 绿字 `!43a047` | `[T#!43a047#口诀：……]` |
| 关键词高亮 | 黄底 `!!fff59d` | `[T#!!fff59d#必然事件]` |
| 术语强调（无色时默认） | 加粗 `[T#B#...]` | `[T#B#线粒体]` |

样式克制：

- 一段内最多 1～2 种样式；整卡颜色不超过 3 种。
- 参数组合用英文逗号无空格：`[T#B,U,!e53935#...]`。

### 3.2 结构规范

- **标题**：批量制卡时每张卡以 `[P#H1,center#标题]` 开头，标题即考点名（3～12 字）；单张简卡可省略标题。
- **正文分段**：一段一个语义单元；长解释拆多段，避免大段文字。
- **列表**：要点用 `[P#L#...]`，二级用 `[P#L,I2#...]`。
- **问答分隔**：问题与答案之间用 `---`，答案放分隔线之后。
- **公式独立成行**：`[E##...]` 从行首开始。

### 3.3 观感原则

- 短句优先，一行一个语义单元。
- 中文与数字/英文之间不加额外空格（跟随原资料习惯）。
- 装饰性符号（如 ★、→、①②）可少量用于视觉分组，不要堆砌。
- 一张卡在手机屏幕上以 2～6 行为宜，超过就拆卡。

## 四、章节、多卡组织与输出

- **章节标记**：`###章节名`（如 `###ch1`，`###` 后紧跟名称）独占一行，开启新章节；一章下可包含多张卡片。
- **卡片分隔**：同一章节内，卡片之间用 `===` 独占一行分隔。
- **章节切换**：开启新章节时直接写 `###章节名`，其前不加 `===`。
- **章节划分**：按原资料的逻辑结构划分章节；同章节内相关卡片放在相邻位置。
- **章节内排序**：概念→细节→辨析→测验，遵循由浅入深。
- **批量规模**：一次生成建议 ≤ 20 张（可按章节分批），优先保证每张的质量；材料很大时分批生成。
- **成组交付**：同一知识点的挖空卡、问答卡、选择题可成组出现，形成"学—记—测"闭环。

输出骨架：

```
###ch1
第一张卡片内容
===
第二张卡片内容
###ch2
第三张卡片内容
```

## 五、质量自查（逐卡执行）

语法层面：逐项过 `markji-syntax.md` 末尾的官方 12 项检查清单。

设计层面：

1. 每处挖空是否都是该考点的重点/难点/易错点？有无随意挖空？
2. 每张卡是否恰好对应一个知识点？挖空是否全部为重点难点易错点、没有水分？
3. 干扰项是否为真实易混概念（选择题）？
4. 配色与结构是否符合统一规范？有无样式堆砌？
5. 手机屏幕上观感如何？是否需要拆卡？
6. 措辞是否与原文一致（未压缩、未同义替换、未增删）？助记是否只出现在 `---` 之后？
