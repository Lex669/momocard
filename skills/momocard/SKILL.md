# 墨墨记忆卡生成（momocard）

生成可直接粘贴进墨墨记忆卡（Markji）的卡片文本。输出必须同时满足三点，缺一不可：

1. **语法正确** — 严格符合官方制卡语法（见 `references/markji-syntax.md`）。
2. **易于背诵** — 原文措辞一字不改，只做分点重排与挖空；一个知识点一张卡，挖空只挖重点、难点、易错点（见 `references/card-design.md`）。
3. **美观统一** — 统一配色与结构规范，观感克制。

## 工作流程

1. **读参考文件**：首次使用或语法细节不确定时，读 `references/markji-syntax.md`；设计卡片前读 `references/card-design.md`。参考 `examples/example-cards.md` 校准输出水准。
2. **分析材料**：先判断材料包含几个知识点——一段材料只讲一个概念/主题时，只建一张卡，不拆分；含多个独立知识点时才逐个成卡。再识别每个知识点的形态（事实/问答/辨析/列举/公式/流程），跳过水分内容。
3. **设计卡片**：为每个知识点选卡型；按挖空策略确定挖空点（重点难点易错点，而非随意挖空；定义句中的限定词必挖，见 card-design.md 1.1）；默认不生成选择题——仅当用户明确要求辨析/测验题时才加入，单知识点材料只出一张整卡挖空卡。
4. **编写卡片**：按统一配色与结构规范排版；不改写材料措辞，只做分点重排（如 定义/分布/组成/功能）与挖空；一个知识点一张卡，挖空覆盖其全部重点难点易错点，编号在卡内从 1 连续且唯一；助记（口诀、陷阱）放在 `---` 之后。
5. **自查**：逐卡执行语法 12 项检查清单 + card-design.md 末尾的设计自查。
6. **输出**：按下方输出格式交付。

## 核心规则速记

- 语法结构 `[名称#参数1,参数2#内容]`；无参数也保留两个 `#`，如 `[E##x+y]`。
- 块级语法（`[P#..]`、`[Choice..]`、`[E##..]`、`---`）必须从一行的第一个字符开始；选择题结尾 `]` 单独占一行。
- 挖空 `[F#正整数#内容]`，相同编号同组；内容中不嵌套语法。
- 样式 `[T#B/I/U/!rrggbb/!!rrggbb#文字]`，颜色 6 位小写十六进制；内容中不放其他语法。
- 普通文字里的中括号转义为 `\[` 和 `\]`；参数区中的 `#`、英文逗号、换行会破坏语法。
- 选择题选项每行以 `* `（正确）或 `- `（错误）开头；多正确必须 `multi`；选项内仅普通文字和 `T` 样式。
- 只使用真实的图片/音频/卡片 ID，绝不编造；拿不到 ID 就不用这些语法。
- 标题只有 `H1`；列表只用 `L`（缩进 `I2`）；对齐一段只一种。
- 粒度原则：一个知识点 = 一张卡片，不把一个知识点拆成多张卡。
- 原文原则：材料措辞一字不改，只做分点重排与挖空（标签可吸收句首指代）；助记（口诀、陷阱）放 `---` 之后。
- 定义句限定词必挖："X是……的……"中的定位、性质、程度限定词（如"镶嵌于""功能性""永久性"）是高频考点，字数再短也不得漏挖。
- 默认不加选择题：用户未明确要求辨析/测验题时不生成选择题；单知识点只出一张整卡挖空卡。
- 输出组织：`###章节名`（如 `###ch1`）独占一行开启章节，章节内卡片用 `===` 独占一行分隔；新章节前不加 `===`。

## 输出格式

- 按**章节**组织：章节标记 `###章节名`（如 `###ch1`，`###` 后紧跟名称）独占一行；一章下可包含多张卡片，卡片之间用 `===` 独占一行分隔；开启新章节时直接写 `###章节名`，其前不加 `===`。
- 所有内容放在**一个代码块**中，用户整体复制粘贴到墨墨记忆卡。
- 章节按原资料的逻辑结构划分，章节内卡片遵循 概念→细节→辨析→测验 由浅入深（辨析与测验卡仅在用户明确要求时加入）。
- 批量制卡时每张卡以 `[P#H1,center#考点标题]` 开头；单张简卡可省略。
- 代码块后用一两句话说明：章节与卡片数量、卡型分布、挖空设计思路（挖了什么、为什么）。
- 材料包含多个知识点时先给拆分方案（哪些章节、每个知识点各一张卡），确认后按章节分批生成（每批 ≤ 20 张）。
